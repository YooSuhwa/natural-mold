# 워크플로 AI 편집 평가 (W5a, 반복 추가 L-d, 2026-11-09)

재실행: `cd backend && .venv/bin/python -m evals.workflow_edit.run`
(모든 응답이 `cache/llm.json`에 있어 재실행은 게이트웨이 호출 0회이고 결과는 결정적이다. 원자료와 제안된 정의는 `results.json`.)
모델: 사내 LiteLLM 게이트웨이 `gpt-5.4-mini`, `claude-sonnet-5`. 경로: API와 같은 `ai_edit.propose`(편집 명령 적용 → 정의 검증 →
게시 검사, 고쳐 보내기 1회). 에이전트는 가짜 5개(문의 분류, 답변 작성, 주간 보고, 웹 조사, 품질 검사).

## 사례

| 사례 | 시작 | 요청 요지 | 통과 조건 |
|---|---|---|---|
| `q3_from_scratch` | 빈 초안 | 분류 → 긴급이면 승인 → 답변 초안, 거절은 실패 | 제안, 게시 검사 0건, 노드 종류(시작·에이전트·판단·승인·출력·실패), 분류·답변 에이전트 |
| `weekly_report` | 빈 초안 | 주간 보고 → 위험이 있으면 승인 후, 없으면 바로 내보내기 | 같은 기준, 주간 보고 에이전트 |
| `research_summary` | 빈 초안 | 웹 조사 → 요약 작성 → 제목·본문 두 필드 출력 | 조사가 요약으로 이어짐, 출력 필드 2개 |
| `edit_timeout` | Q3 템플릿 | 승인 기한을 2시간으로, 나머지 그대로 | 바뀐 노드가 `review` 하나, `timeout_minutes` 120, 연결 그대로 |
| `rewrite_loop` | 빈 초안 | 작성 → 검사, 떨어지면 의견을 반영해 다시(최대 3번), 넘으면 내 승인 | 반복 1개, `max_rounds` 3, 한도 초과 갈래가 승인, 다시 쓰는 단계가 앞 회차 검사 의견을 읽음(`previous`) |
| `ambiguous` | 빈 초안 | "문서 처리하는 흐름 하나 만들어 줘" | 되묻기(`question`) |

## 결과

| 모델 | 통과 | 고쳐 보내기 | 입력·출력 토큰(합) |
|---|---|---|---|
| `gpt-5.4-mini` | 6/6 | 2건(`q3_from_scratch`: 입력을 정하지 않고 `/inquiry`를 참조 → 게시 검사가 잡아 한 번에 고침; `rewrite_loop`: 입력 이름을 한글로 써서 이름 규칙 위반 → 한 번에 고침) | 43,415 / 4,644 |
| `claude-sonnet-5` | 6/6 | 1건(`rewrite_loop`: 인자를 문자열 하나로 보냄 → 한 번에 고침) | 57,427 / 6,040 |

- 업무 4건(반복 포함)을 두 모델 모두 게시 검사 0건으로 만들었다. 반복은 판단의 "아니오" 갈래를 작성 단계로 되돌리고
  `repeat.max_rounds` 3, `limit` 갈래를 승인으로 이었으며, 작성 프롬프트에 검사 의견을 `previous` 참조로 넣었다.
- 고치기 요청(`edit_timeout`)은 두 모델 모두 `update_node` 한 개로 승인 노드만 바꿨다. 모호한 요청에는 둘 다 되물었다.

### L-d에서 고친 것 (평가로 찾음)

1. **gpt가 다시 쓰는 단계에 검사 의견을 넘기지 않았다**(반복은 맞지만 같은 글만 되풀이하는 흐름). 시스템 프롬프트에 "검사에 떨어져
   다시 하는 단계는 그 의견을 `previous` 참조로 받아야 한다"와 반복 예시 하나를 넣었다.
2. **gpt가 출력 형식에 `minItems`를 썼고**, 고쳐 보내도 반복했다. 허용 키(type, properties, required, items, enum,
   description)를 프롬프트에 적었다.
3. **gpt가 새 노드를 `update_node`로 만들려 했다.** 명령 설명을 "`add_node`는 초안에 없는 ID, `update_node`는 있는 ID"로
   바꾸고, 고쳐 보내기 메시지에 "새 노드는 `add_node`로"를 붙였다.
4. **Claude가 올바른 인자를 `{"$PARAMETER_NAME": {...}}`로 한 번 더 감싸 보냈다**(게이트웨이를 거친 Claude 도구 호출의 버릇).
   서버가 알 수 없는 키 하나로 감싼 인자를 한 겹 벗긴다(`ai_edit.unwrapped`, 단위 시험).

## 한계

- 사례 6개 × 모델 2개로 작다. 승인 대상 범위가 넓어지는 W5b 화면 시험과 실제 사용 기록으로 넓힌다.
- 에이전트 이름·설명이 요청과 잘 맞는 경우만 봤다. 맞는 에이전트가 없을 때 되묻는지는 시스템 프롬프트 규칙으로만 둔다.
