# F09 한국어 기억 검색 평가

## 자료와 판정 기준

보고 자료는 2026-11-27에 고정한 `independent_ko.json`이다. 다섯 가상 사용자의 기억 142개와 질문 150개를 담았다. 같은 단어, 조사, 바꿔 말하기, 시간, 여러 턴, 무관 질문이 각 25개다. 보고 세트에서 임계값을 조정하지 않는다. 파일 SHA-256은 `9eb543ed3fff0302cfabb55a7ea127534cc34eca663c5fdd06319f38b578898a`다. 실행기는 질문과 이전 턴, 기억 ID와 본문을 기존 `dataset.json`의 조정·보고 양쪽과 대조하고 범주별 독립 묶음 수를 검증한다.

기준선은 제품의 접미사 분석기와 키워드 기준 0.30이다. 후보는 같은 키워드에 승인된 임베딩 모델의 코사인 점수를 결합하는 제품 RRF 경로다. 운영자는 평가 전에 조직, 모델 등록 ID, 차원, 제공자, 엔드포인트, 코사인 기준값을 정한다. 이전 보고서가 제시한 `text-embedding-3-large@1024`의 다음 후보 범위는 0.40~0.42다. 같은 보고 세트의 결과를 보고 수치를 고른 후보는 평가용 새 세트가 필요하다.

### 이번 로컬 후보

키워드 결과를 기록한 뒤, 후보 결과를 열기 전에 다음 구성을 한 번 평가하기로 정했다. 합성 시험 조직에서 선택한 `openai_compatible` 로컬 엔드포인트(`http://127.0.0.1:59367/v1`)에 `inferedge/moss-minilm@bootstrap-2026-08-11` 384차원과 기준값 0.42를 사용한다. 로컬 ORT 가중치 SHA-256은 `25044e4079b5a7b519d30ccf90b3e233fedb47ef1c89758b5729830a98a676e2`, 토크나이저 SHA-256은 `be50c3628f2bf5bb5e3a7f17b1f74611b2561a3a27eeab05e5aa30f411572037`이다. 이 배포본에 한국어 학습을 명시한 정보는 없다.

두 조건을 동시에 충족하면 후보가 통과한다.

- 무관한 질문에서 선택 목록이 비어 있는 비율이 0.90 이상이어야 한다.
- 바꿔 말하기 recall@10이 키워드 기준선보다 높아야 한다.

## 측정 방법

실제 조직 데이터와 분리한 메모리 내 SQLite에 가상 사용자 한 명의 승인된 기억을 재현하고 `memory_recall.rank`와 `select_within_budget`를 실행한다. 저장 시각과 UUID를 고정해 순위 동률을 재현한다. 시간 질문의 사건 날짜는 자료의 날짜를 사용한다. 여러 턴 질문은 현재 문장과 선행 문장을 제품과 같은 순서로 전달한다. 이 세트의 질문은 모두 새 검색을 수행한다. 인사와 단순 재개는 제품의 별도 경로에서 처리한다.

- **회상률**은 각 질문의 정답 중 실제 선택 목록 처음 10개에 든 비율을 낸 뒤 범주 안에서 평균한다. 목록에는 범위별 상한 4개와 전체 예산 1,500토큰을 적용한다. 무관 질문은 기억을 하나라도 선택하면 실패다.
- **추가 토큰**은 제품 추정기로 계산한 전체 기억 블록의 토큰 수다. 빈 블록은 0이며, 후보 보고서는 키워드 대비 질문별 차이의 평균도 기록한다. 모델이 청구하는 입력 토큰은 측정하지 않는다.
- **p95 시간**은 질문별 검색·선택·블록 렌더링 경과 시간의 최근접 순위 백분위다. 후보는 캐시 없이 매 질문 실제 제공자에 질의하고 그 왕복 시간을 포함한다. 기억 벡터를 미리 만드는 시간, DB 초기화, 채팅 생성은 제외한다. 제공자가 실패하거나 벡터 수·형식·정규화가 맞지 않으면 전체 후보 측정을 중단한다.
- **95% 구간**은 단일 정답 또는 무관 질문의 독립 이진 관측에는 Wilson 점수 구간을 쓴다. 복수 정답 질문의 평균, 비용과 지연은 질문 묶음을 복원추출하는 백분위 부트스트랩을 쓴다(2,000회, 시드 15). 표본 수와 구간을 각 측정값에 함께 기록한다. 판정은 반올림 전 점추정으로 한다.

## 실행

백엔드 디렉터리에서 실행한다. 출력 경로에는 새 파일명을 지정한다.

```sh
uv run python -m evals.memory_recall.independent --output /tmp/moldy-f09-keyword.json
```

조직 관리자가 임베딩 제공자와 모델을 승인한 경우, 해당 조직에서 메모리 임베딩에 선택한 모델 ID와 사전에 정한 코사인 기준을 지정한다. 실행 환경의 `DATABASE_URL`과 모델 자격증명 복호화 설정을 사용한다. 각 가상 사용자의 기억과 각 질의를 보내기 전에 회사·조직의 모델 카탈로그와 자격증명 대상 주소를 다시 확인한다. 제공자에는 고정한 합성 자료만 전송한다.

```sh
uv run python -m evals.memory_recall.independent \
  --tenant-id "$TENANT_ID" --org-id "$ORG_ID" --approved-model-id "$MODEL_ID" \
  --cosine-floor "$PREREGISTERED_FLOOR" --output /tmp/moldy-f09-candidate.json
```

운영자가 결과와 질문별 선택 목록을 검토하고 통과한 보고서 전체를 서버의 `MEMORY_RECALL_QUALITY_DIR/<tenant-uuid>/<model-uuid>.json`에 설치한다. 이어 회사 관리자가 비교할 조직으로 전환해 기억 설정에서 비교 시험 또는 실제 적용을 선택한다. 같은 회사의 다른 조직은 자체 설정을 사용하며, 회사 임베딩 모델을 변경하면 모든 조직의 선택이 해제된다. 현재 독립 평가는 접미사 분석기(키워드 기준 0.30)를 대상으로 한다. OpenSearch/Nori를 사용하는 구성은 해당 분석기를 검증한 독립 평가가 필요하다. 키워드만 평가한 결과는 `candidate: null`, `gate.passed: false`다.
